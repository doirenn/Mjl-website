# GOAT 2027 — sample HTML de referencia

Este archivo es el sample HTML de Marian para la landing de **GOAT 2027: Your Greatest Year Ever**.

Sirve como referencia de estructura, copy y estilo para el build en Astro, en esta misma rama `goat-2027`. No es la versión final ni una página lista para producción: las imágenes de stock, el formulario de reserva y los botones de pago todavía son de muestra.

Cuando el build en Astro esté aprobado, esta carpeta puede retirarse.
